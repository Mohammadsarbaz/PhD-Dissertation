## 📝 Abstract

This dissertation investigates safe trajectory optimization and optimal control theory for high-dimensional, nonlinear dynamic systems operating under bounded external disturbances and dynamic uncertainty. By combining **Differential Dynamic Programming (DDP)** and **Min-Max differential game theory** with learning-based techniques, the proposed framework enables robust, real-time control synthesis for complex robotic systems.

---

## 🔑 Key Research Topics & Methodologies

* **Min-Max Differential Dynamic Programming (Min-Max DDP):** Formulation for dynamic games and worst-case disturbance rejection.
* **Optimal Control & Differential Games:** Safe trajectory generation under dynamic constraints and competitive agents (e.g., Homicidal Chauffeur problem).
* **Learning-Based Control:** Integrating function approximators to overcome computational bottlenecks in high-dimensional trajectory optimization.
* **Robotics Applications:** Experimental and simulation validation on autonomous systems.
